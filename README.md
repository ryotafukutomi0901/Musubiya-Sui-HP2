# 結び家SUI モック（2案目）

古民家レンタルスペース 結び家SUI（静岡県富士宮市）のサイトのモック、2案目。2026-11-15 の CEO 指示で作った。

中身（ページの分け方、文章、数字、写真、予約の動き）は1案目の [Musubiya-Sui-HP](https://github.com/ryotafukutomi0901/Musubiya-Sui-HP) と同じ。変えたのは見た目と並べ方だけで、提案資料のデザインA案「静けさと余白」にあたる。静的な HTML・CSS・JavaScript だけで、ライブラリは使っていない。本番のコードではない。

## 見方

このフォルダで次を実行して、http://localhost:4311/ を開く。予約管理は http://localhost:4311/admin/ （ログイン画面のボタンを押せば入れる。何も送らない）。

```bash
python3 -m http.server 4311 --bind 127.0.0.1
```

社内では、プレビューの `musubiya-mock2`（AI-Company 直下の `.claude/launch.json`）でも起動できる。

## 予約（2案目だけの分け方）

2026-11-15 の CEO 指示で、2案目だけ、レンタルスペースとピラティスで予約を分けた。どちらもカレンダーで選ぶ。データは1案目と同じ見本で、このブラウザの localStorage に置くだけ。どこにも送らない。

**お客様の画面**

- 入口：`reserve.html` は2つの大きな入口（スペースを借りる／ピラティスを予約する）だけにした。以前の `reserve.html#rental` などのリンクは、分けたページへ送る。
- 読んでいるページから、そのまま予約へ進める。
  - スペース・利用シーン・料金・ご利用案内からは、レンタルの空き状況へ。
  - 利用シーンから進んだときは、ご利用の目的を選んだ状態で開く（`?purpose=`）。
  - ピラティスのページの「体験を予約する」からは、体験の料金で開く（`?trial=1`）。
- ヘッダーの右上のボタンと、スマホの画面下のボタンは、ページに合わせて変わる。
  - スペースまわりのページでは「空き状況を見る」、ピラティスのページでは「ピラティスを予約」、そのほかは「ご予約・空き状況」。
  - 予約のページの中では、自分のページを指さないよう「ご予約の確認」か「ご予約」にする。
- フッターの写真の帯に「空き状況を見て申し込む」、フッターの下に「ご予約の確認・変更」を足した。利用の相談のページの上にも、日にちが決まっている人向けの案内を置いた。
- レンタルは4段に分けた。
  - 日時を選ぶあいだ、画面の下の帯に「いま選んでいる希望」と「次へ」を出し続ける。
  - 完了の画面には、このあとの流れ（24時間以内の連絡 → 振込 → 前日の案内）を出す。
- ピラティスは3段。
  - プラン（すべて・セミパーソナル・パーソナル）と「はじめての方」で絞り込むと、カレンダーの数字と料金が変わる。
  - 完了の画面からカレンダーアプリに入れられる。
- 確認の画面は、レンタルとピラティスをタブで分けた。
  - この端末で申し込んだ予約は、カレンダーと一覧に出る。
  - ほかの端末で申し込んだときは、番号と電話番号で探す。
  - ピラティスの回の変更は、同じプランの回にだけできる。

**予約管理（/admin/）**

- 左のメニューを「レンタルスペース」「ピラティス」「共通」に分けた。
- ホームは左がレンタル（承認待ち・変更の希望・入金待ち・今日の貸切）、右がピラティス（今日のレッスン、この7日間の埋まり具合、体験の方の数）。
- レンタルスペース
  - カレンダー：月と週。承認待ちの希望は点線。レッスンとイベントは「貸せない時間」として薄く出す。
  - 申込み：承認・お断り・入金・変更の承認・キャンセル。
- ピラティス
  - カレンダー：月と週。回ごとに人数と定員を出し、満席は色を変える。レンタルは「使えない時間」として薄く出す。
  - 回を押すと右に開き、そこで次のことができる。
    - 予約した方の一覧
    - 定員の変更
    - 別の回への移動とキャンセル
    - 電話やLINEで受けた予約を入れる
  - 予約した方（体験の方だけでも見られる）と、回と定員の画面がある。
- 共通：休業日、お客様へのお知らせ、お知らせとInstagram、料金と設定（レンタルとピラティスで欄を分けた）。
- カレンダーは、月の表はその月の1日から、週の表は日曜から始まる。
- 日にちを押すと、その日の予定が月の表の右（週の表では下）に出る。
  - 9:00〜21:00 の帯で、埋まっている時間がひと目で分かる。
  - レンタルでは、その日の空いている時間を出す（電話で聞かれたときにすぐ答えられるように）。
  - ピラティスでは、回ごとに人数と予約した方の名前を出す。「この日に回を足す」から、その日を選んだ状態で回を足せる。
  - 予定を押すと、申込みの内容か、回の詳しい内容が開く。「‹ ›」で前後の日に移れる。
- 月の表には、承認待ち・変更の希望がある日に数字の印を付けた。土日の色を分け、過ぎた日は薄くした。

## 画像

```
assets/img/
├── photo/  実写。Instagram の投稿から仮に切り出した部屋と建物の写真
├── gen/    生成画像。ChatGPT で作った「イメージ」。左上に「イメージ（生成画像）」と出る
└── ig/     Instagram の投稿の一覧画像
```

実写には右下に「仮：Instagramの投稿より」と出る。スペースのページの写真の欄は実写だけを使う（最初の大きな画像だけは、Instagram の写真では粗いので生成画像にした。2026-11-15）。講師、トイレ、駐車場、外観、地図は灰色の箱のまま。

## 守ったこと

- 分からない値は ○ にして、赤字の「※要確認」を付けた。公開前に必ず埋める。
- 生成画像を実写のように置かない。
- 参考サイトからは並べ方だけを借りた。
