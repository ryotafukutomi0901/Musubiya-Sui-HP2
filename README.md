# 結び家SUI モック（2案目）

古民家レンタルスペース 結び家SUI（静岡県富士宮市）のサイトのモック、2案目。2026-11-15 の CEO 指示で作った。

中身（ページの分け方、文章、数字、写真、予約の動き）は1案目の [Musubiya-Sui-HP](https://github.com/ryotafukutomi0901/Musubiya-Sui-HP) と同じ。変えたのは見た目と並べ方だけで、提案資料のデザインA案「静けさと余白」にあたる。静的な HTML・CSS・JavaScript だけで、ライブラリは使っていない。本番のコードではない。

## 見方

このフォルダで次を実行して、http://localhost:4311/ を開く。予約管理は http://localhost:4311/admin/ （ログイン画面のボタンを押せば入れる。何も送らない）。

```bash
python3 -m http.server 4311 --bind 127.0.0.1
```

社内では、プレビューの `musubiya-mock2`（AI-Company 直下の `.claude/launch.json`）でも起動できる。

## 並べ方

senya-gafu.com の並べ方を参考にした。借りたのは配置の考え方だけで、文章・画像・コードは使っていない。

| 部品 | 中身 | 使っている所 |
|---|---|---|
| 全面の写真と、写真の上の縦書きのメニュー | ページの最初は透明なヘッダーに白い文字。右上に縦書きでページを並べる。写真を過ぎると白い帯になり、「利用の相談」と三本線に変わる | 全ページ |
| 縦書きのことば | TOP の最初の画面の左下に、コンセプトの一文を縦書きで置く | TOP |
| 散らした写真 | 縦書きの名前と文を中央に置き、まわりに大きさの違う写真をずらして置く。スクロールに合わせて少しずつ動く | TOP「この場所について」 |
| 番号つきの一覧と大きな写真 | 左に1〜6の一覧、右に大きな写真。スクロールすると、いまの項目が大きくなり、写真が切り替わる。スマホでは写真つきの縦の一覧にする | TOP「利用シーン」 |
| 灰色の面のカード | 写真の下に「名前｜説明」 | TOP「スペース」 |
| 見出しを左、文を右 | 大きな見出しと短い説明を左右に分ける | TOP「料金」「流れ」「最近のようす」「よくあるご質問」 |
| 写真と文を左右に交互に | 名前、縦の線、小さな添え書き、文、下線のリンク | TOP「ピラティスと、アクセス」、下層ページの用途ごとの段 |
| 横に流れるカード | 写真、日付と小さな札、題。矢印でも動かせる | TOP「最近のようす」（Instagram） |
| 写真の帯の誘い | 暗い写真の上に、左に2行のことば、右に相談・見学・LINE の入口 | 全ページのフッターの上 |
| フッター | 大きな名前、住所、縦書きのページ一覧、規約などの小さなリンク | 全ページ |
| 全画面のメニュー | 写真の上に、縦書きのことばとページの一覧 | 全ページ |
| 下層ページの最初の画面 | 全面の写真の帯に、白い大きな題と添え書き。その下にパンくず | 下層ページ |

色は白地に墨色、面の灰色。字体は結び家SUIのもの（見出しは Shippori Mincho、本文は Zen Kaku Gothic New、数字と英字は Cormorant Garamond）。

## 画像

```
assets/img/
├── photo/  実写。Instagram の投稿から仮に切り出した部屋と建物の写真
├── gen/    生成画像。ChatGPT で作った「イメージ」。左上に「イメージ（生成画像）」と出る
└── ig/     Instagram の投稿の一覧画像
```

実写には右下に「仮：Instagramの投稿より」と出る。スペースのページは実写だけを使う。講師、トイレ、駐車場、外観、地図は灰色の箱のまま。

## 守ったこと

- 分からない値は ○ にして、赤字の「※要確認」を付けた。公開前に必ず埋める。
- 生成画像を実写のように置かない。
- 参考サイトからは並べ方だけを借りた。
